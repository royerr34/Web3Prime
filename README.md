# Web3Prime

Web3Prime enables real-time data processing and auto-scaling architecture for high-performance applications on a decentralized, cloud-based protocol network.

With Web3Prime, you get a lightweight tool that stays out of your way.

**What you get**

- Web3Prime enables real-time data processing
- and auto-scaling architecture for high-performance
- applications on a decentralized, cloud-based

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Prime.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Web3Prime is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
